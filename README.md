# 🏗️ Advanced Data Modelling & Relationship Management

## 📌 Overview
This project focuses on the structural side of data analytics—transforming messy, disconnected datasets into a high-performance relational model. Using **excel data modeling project.xlsx**, I built a robust architecture that allows for seamless cross-table analysis and complex metric calculation.

## 🚀 Key Features
* **🔗 Star Schema Architecture:** Established relationships between Customers, Products, Stores, and Sales tables using Power Pivot.
* **📊 DAX Implementation:** Created custom Data Analysis Expressions (DAX) to calculate Total Revenue, Profit Margins, and Average Order Value (AOV).
* **🧹 Data Normalization:** Cleaned and structured 12 distinct sheets to ensure data integrity and eliminate redundancy.
* **💡 Multi-Currency Support:** Integrated automated exchange rate conversions for global sales reporting.

## 🛠️ Tech Stack
* **Excel Power Pivot** (Data Modeling & Relationships)
* **DAX** (Measures & Calculated Columns)
* **Power Query** (ETL - Extract, Transform, Load)

## 📁 Project Structure
* `Customers`: Demographic data and age grouping.
* `Sales`: Fact table containing transactional records.
* `Products/Stores`: Dimension tables for categorical filtering.
* `Insights`: Strategic recommendations based on the data model.
